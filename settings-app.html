שם המשתמש / ריפו
מפתח גישה (Personal Access Token)
איך יוצרים מפתח גישה?
1. GitHub → תמונת פרופיל → Settings → Developer settings
2. Personal access tokens → Fine-grained tokens → Generate new token
3. Repository access → הריפו שלך בלבד
4. Permissions → Contents + Actions → Read and write
5. Generate token, ותעתיק את המפתח (מוצג פעם אחת בלבד)
הקוד רץ אוטומטית כל 15 דקות דרך GitHub Actions, ובודק אם הגיע הזמן לסריקה לפי התדירות שהוגדרה.
אם משהו לא עובד, הבדיקה הראשונה היא לוג ההרצה בטאב Actions בריפו.
