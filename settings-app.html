חיבור ל-GitHub

איך יוצרים מפתח גישה?
1. ב-GitHub: תמונת פרופיל ← Settings ← בסוף לגמרי בצד: Developer settings
2. Personal access tokens ← Fine-grained tokens ← Generate new token
3. Resource owner: תבחר את החשבון שלך
4. Repository access: "Only select repositories" ← תבחר את pcs-monitor
5. Permissions ← Repository permissions ← Contents ← "Read and write"
6. Generate token, ותעתיק את המפתח (הוא מוצג פעם אחת בלבד)
